# 👁️ Renato Vision 3D

Câmera, galeria e visualização 3D de fotos e vídeos — 100% no navegador.

## ✨ Funcionalidades

- 📷 Câmera com 15 filtros em tempo real
- 🎥 Gravação de vídeo
- 🌐 Globo 3D interativo com todas as fotos
- 🖼️ Galeria Premium com IndexedDB
- 🎨 90 temas de interface
- 🌙 Modo noturno
- 🧊 Visualizador 3D

## 🚀 Como usar

Acesse: https://SEU-USUARIO.github.io/renato-vision-3d/

## 📱 Instalar no celular

1. Abra no Safari/Chrome
2. Menu → "Adicionar à Tela de Início"
3. Pronto, funciona como app

## 🔒 Privacidade

Todas as fotos ficam salvas **localmente** no seu dispositivo.
Nada é enviado para servidores.
